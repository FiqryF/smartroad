Endpoint Internal

API Backend Berdasarkan Bagian

Setiap bagian di bawah menjelaskan fungsi modul, endpoint yang dipakai, autentikasi, role akses, dan file backend tempat endpoint dibuat.

Auth API

Bagian ini dipakai untuk registrasi akun dan login. Login menghasilkan JWT token untuk akses halaman user, petugas, dan admin.

File: app/routes/auth_routes.py

POST /api/auth/register Publik

Membuat akun user baru.

POST /api/auth/login Publik

Login dan mengembalikan access token JWT.

Profile API

Bagian ini dipakai untuk mengambil dan mengubah data profil user, termasuk password dan foto profil.

File: app/routes/profile_routes.py

GET/api/profile/user-profile

Mengambil profil user login. Auth: JWT.

POST/api/profile/update-profile

Update nama, telepon, dan alamat. Auth: JWT.

POST/api/profile/update-password

Update password. Auth: JWT.

POST/api/profile/upload-photo

Upload foto profil. Auth: JWT.

Reports API

Bagian ini mengelola laporan kerusakan jalan, riwayat laporan, status, review, notifikasi, dan ringkasan publik.

File: app/routes/report_routes.py

GET/api/reports/public-summary

Statistik publik di halaman utama. Auth: tidak.

POST/api/reports/submit

Kirim laporan kerusakan jalan. Auth: JWT user.

GET/api/reports/user

Riwayat laporan milik user login. Auth: JWT.

POST/api/reports/<report_id>/review

Review laporan selesai. Auth: JWT pemilik laporan.

GET/api/reports/notifications/user

Ambil notifikasi user. Auth: JWT.

PUT/api/reports/notifications/user/read

Tandai notifikasi sudah dibaca. Auth: JWT.

Admin API

Bagian ini hanya untuk admin: melihat semua laporan, mengubah status, melihat user, memilih petugas, dan memantau chat CS.

File: app/routes/admin_routes.py dan app/routes/report_routes.py

GET/api/reports/all

Semua laporan untuk dashboard admin. Auth: JWT admin.

PUT/api/reports/<report_id>/status

Update status dan assign petugas. Auth: JWT admin.

GET/api/admin/users

Daftar semua user. Auth: JWT admin.

GET/api/admin/petugas

Daftar petugas. Auth: JWT admin.

GET/api/admin/dashboard-stats

Statistik dashboard contoh. Auth: JWT admin.

Petugas API

Bagian ini dipakai petugas lapangan untuk melihat tugas dan menyelesaikan laporan dengan bukti perbaikan.

File: app/routes/report_routes.py

GET/api/reports/assigned

Laporan yang ditugaskan. Auth: JWT petugas.

POST/api/reports/<report_id>/complete

Selesaikan laporan dan upload bukti. Auth: JWT petugas.

CS Chat API

Bagian ini dipakai user dan admin untuk percakapan CS berdasarkan laporan tertentu.

File: app/routes/report_routes.py

GET/api/reports/cs/conversations

Daftar percakapan CS. Auth: JWT admin.

GET/api/reports/<report_id>/cs-messages

Ambil pesan chat laporan. Auth: JWT admin/pemilik laporan.

POST/api/reports/<report_id>/cs-messages

Kirim pesan chat laporan. Auth: JWT admin/pemilik laporan.

API Eksternal

API dari Luar Aplikasi

Bagian ini adalah layanan pihak luar yang dipakai frontend untuk data wilayah, avatar, chart, dan peta.

Dipakai di halaman laporan.

/provinces.json /regencies/<idProvinsi>.json /districts/<idKota>.json

RandomUser Portraits

https://randomuser.me/api/portraits/...

Fungsi: gambar avatar testimoni statis di landing page.

Chart.js CDN

Dipakai di dashboard admin.

https://cdn.jsdelivr.net/npm/chart.js

Fungsi: membuat grafik tren laporan dan kategori kerusakan.

Leaflet CDN

Dipakai di dashboard admin.

https://unpkg.com/leaflet@1.9.4/...

Fungsi: menampilkan peta dan titik koordinat laporan.

Alur Autentikasi Admin

1

Admin login melalui endpoint POST /api/auth/login.

2

Backend membuat JWT dengan identity email dan claim role=admin.

3

Token disimpan di sessionStorage.jwtToken.

4

window.authFetch() mengirim header Authorization ke setiap request admin.

5

Backend mengecek JWT dan decorator @admin_required().
